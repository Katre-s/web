> 校园二手书籍交易平台 | 文聚学府，百事通达
>

## 一、整体架构

```
┌─────────────────────────────────────────────────────────┐
│                    用户访问层                            │
│  电脑浏览器    手机浏览器(PWA)    Android APK(Capacitor)   │
└──────────┬──────────┬──────────────┬───────────────────┘
           │          │              │
           ▼          ▼              ▼
┌─────────────────────────────────────────────────────────┐
│              前端 SPA（Vue3 + Vite）                      │
│  同一套代码，三端共用：响应式 UI + PWA + Capacitor 打包    │
│  baseURL: /api（Web 同源）或 http://121.40.219.139:3000/api（APK）│
└──────────────────────────┬──────────────────────────────┘
                           │ HTTPS / JWT Bearer
                           ▼
┌─────────────────────────────────────────────────────────┐
│           后端 REST API（Express + Sequelize）            │
│  端口 3000 | CORS 全开 | JWT 鉴权 | multer 文件上传        │
└──────────────────────────┬──────────────────────────────┘
                           │ Sequelize ORM
                           ▼
┌─────────────────────────────────────────────────────────┐
│              MySQL 数据库（campus_trade）                 │
│  16 张表 | 外键关联 | Sequelize sync 自动建表              │
└─────────────────────────────────────────────────────────┘
```

| 移动端 | Capacitor 8（内嵌打包）+ PWA（manifest + Service Worker）                |

```
请求 → cors() → express.json() → 路由 → verifyToken? → adminOnly? → controller → errorHandler
```

### 5.4 启动迁移（`app.js` start()）

1. `sequelize.sync()`（仅建缺失表；`DB_SYNC_ALTER=true` 时才 alter）
2. **Book 迁移**：Book 表空时从 Product 表迁移书籍元数据
3. **userNo 迁移**：为无 userNo 的用户分配 8 位递增 ID
4. **对话合并**：合并同用户对的重复对话（双向聚合）
5. **定时清理**：每小时删除 24h 无消息的过期对话

## 七、功能实现架构

### 7.1 用户认证

```
注册：邮箱 + 验证码 + 密码 + 校区（三重校验：邮箱正则/校区白名单/密码长度）
  └─ emailService.sendVerificationCode（6 位码，5 分钟有效，Map 存储）
登录：邮箱 或 8位userNo + 密码 → JWT（含 id/email/nickname/role/campus，7天）
  └─ 封禁校验：status === 'banned' 拒绝
找回密码：邮箱 → 验证码 → 新密码
JWT 鉴权：middlewares/auth.js verifyToken 解析 Bearer token
管理员：middlewares/admin.js adminOnly（role === 'admin'）
```

### 7.2 书籍聚合（Book + Product 双层）

```
Book（板块）          Product（卖家在售）
  ISBN ──聚合──→  多个 Product
  bookTitle         price / condition / delivery
  bookCover         status: available/sold
  viewCount         sellerId

聚合逻辑（booksController）：
  listBooks: 按 ISBN 分组（无 ISBN 按书名+作者），返回最低价 + 卖家数
  bookDetail: 返回板块信息 + 所有卖家报价 + viewCount+1
  homeStats: 今日新上架 + 7日趋势 + 热销排行
```

### 7.3 AI 智能助手

```
前端：AiFloat（悬浮窗）/ AiChat（独立页）
  └─ agentApi.chat(message, history) → POST /api/agent/chat
      └─ agentService.chatWithAgent
          ├─ SYSTEM_PROMPT：意图分类 buy/sell/search/order/help/chat
          ├─ 模型：AI_MODEL 环境变量（默认 GLM-5.3-Flash）
          ├─ 请求：OpenAI 兼容 chat/completions（axios + Bearer Key）
          └─ 返回：{ intent, reply } JSON（兼容 markdown 包裹）

多轮记忆：history 随请求发送（最近 10 条）
持久化：localStorage key ai_chat_messages
降级：未配置 AI_API_KEY → 本地规则兜底
```

### 7.4 扫码识别（视觉模型）

```
前端：Trade（买书）/ Publish（卖书）
  └─ 两步识别：① 拍封面（front）→ 书名/作者/出版社 ② 拍封底（back）→ ISBN
  └─ 核对弹窗：信息可编辑 + 封面预览 + 市场匹配数 + 更换封面
  └─ 买书 → 询问加入求购；卖书 → 自动填充表单 + 设置价格

后端：bookController.scanBook
  └─ aiService.scanBookImage(imagePath, mode)
      ├─ sharp 预处理：EXIF 旋转 + 压缩至 1280px + JPEG(质量82)
      ├─ 视觉模型：Qwen3-VL-8B-Instruct（base64 + image_url）
      ├─ mode=front：提示词专注封面（书名必填）
      ├─ mode=back：提示词专注 ISBN 条形码
      └─ 失败重试 1 次，超时 45s
  └─ enrichBookInfo(isbn)：本地 Book → Product → OpenLibrary/GoogleBooks 补全
  └─ 返回：书籍信息 + cover（识别照片）+ marketMatches（在售/求购数）
```

### 7.5 书单智能导入

```
前端：BookListUpload（textarea，每行一个 ISBN）
  └─ bookApi.processBookList → POST /api/book/process-booklist
      └─ bookController.processBookList
          ├─ 有卖家的书 → 自动加入购物车（查重跳过）
          ├─ 无卖家的板块 → 加入求购清单
          └─ 无板块的 ISBN → 查外部 API 补全 → 创建板块 → 加入求购
```

### 7.6 购物车 + 订单

```
购物车：CartItem（userId + productId）
  └─ list：include product → seller（id/userNo/nickname/avatar/campus）
  └─ Cart.vue：每项"联系卖家" + 底部"一键联系全部卖家"（去重逐个创建对话）

订单：Order + OrderItem（含 sellerId，支持多卖家一单）
  └─ create：商品置 sold，创建 Order + OrderItems
  └─ Profile.vue：在售/已售分支，已售显示买家 + "联系买家"
```

### 7.7 对话系统

```
Conversation（buyerId + sellerId + productId，按用户对聚合）
  └─ startConversation：双向查找（A→B 或 B→A 算同一对话）
      └─ 复用时只更新 productId；新建时自动发首条消息
  └─ ChatMessage（conversationId + senderId + content + isRead）

前端 Chat.vue：
  桌面：左侧联系人列表 + 右侧聊天窗
  手机：两级页面（列表 → 聊天详情，返回键拦截）
```

### 7.8 后台管理（Admin）

```
权限：meta.admin + adminOnly 中间件
Admin.vue 五大模块：
  ① 数据概览：统计卡片 + 最新用户
  ② 帖子管理：热点列表 + 上移/下移排序 + 物理删除
  ③ 通知管理：广播 + 单发
  ④ 新书上架 / 板块编辑：六字段可编辑 + ISBN 唯一性
  ⑤ 用户管理：搜索 + 封号/解封 + 设管理员 + 更改用户ID
```

### 7.9 中英文切换（i18n）

```
i18n/index.js：setLang / currentLang + vue-i18n 初始化
zh.js / en.js：全量文案（nav/tabbar/ai/trade/profile/admin/...）
切换入口：NavBar 语言下拉（桌面）/ 半页面板（手机）
13 个页面/组件全部接入 $t()，数据值不翻译
```

## 十、关键设计决策

| 决策                   | 原因                                 |
| -------------------- | ---------------------------------- |
| Book + Product 双层模型  | 书籍按 ISBN 聚合展示，同书多卖家报价对比            |
| 对话按用户对聚合             | 同一用户无论买卖方向只保留一个对话框                 |
| AI 走 OpenAI 兼容接口     | 可在智谱/SiliconFlow/Ollama 间切换，仅改环境变量 |
| Capacitor 内嵌打包（非在线壳） | 独立安装、启动快、UI 离线可用                   |
| usesCleartextTraffic | 后端 HTTP 非 HTTPS，Android 9+ 需放行明文   |
| sharp 图片预处理          | 手机大图/HEIC 压缩，避免视觉模型 400 拒绝         |
| sync() 默认不 alter     | 避免 alter: true 每次启动锁表卡顿            |
| tar.gz 部署（非 zip）     | Windows zip 反斜杠路径 Linux 解压目录结构错    |
