# 文衡 Web 端 - 宝塔面板部署指南

## 一、本地构建

```bash
# 1. 安装依赖
npm install

# 2. 本地开发
npm run dev

# 3. 生产构建（生成 dist 目录）
npm run build
```

构建完成后，`dist/` 目录就是需要部署的静态文件。

## 二、宝塔面板部署步骤

### 前提条件
- 已安装宝塔面板
- 已安装 Nginx（宝塔默认安装）
- 已安装 PM2 管理器（宝塔软件商店 → 搜索 PM2）
- 已安装 MySQL（用于后端数据库）

### 步骤 1：创建站点
1. 宝塔面板 → 网站 → 添加站点
2. 域名：填你的域名（如 `campus.example.com`）或服务器 IP
3. 根目录：`/www/wwwroot/campus-trade-web`
4. PHP版本：纯静态
5. 点击提交

### 步骤 2：上传前端文件
1. 宝塔面板 → 文件 → 进入 `/www/wwwroot/campus-trade-web`
2. 将本地 `dist/` 目录内的所有文件上传到此目录
3. 确保 `index.html` 在根目录下

### 步骤 3：配置伪静态（重要）
1. 网站 → 站点设置 → 伪静态
2. 粘贴 `deploy/bt-nginx.conf` 中的全部内容
3. 保存

> 伪静态规则解决两个问题：
> - Vue Router history 模式刷新 404
> - `/api` 请求反向代理到后端 Node.js

### 步骤 4：部署后端 API
1. 宝塔面板 → 文件 → 创建目录 `/www/wwwroot/campus-trade-server`
2. 上传后端代码到此目录
3. 宝塔面板 → PM2 管理器 → 添加项目
   - 启动文件：`/www/wwwroot/campus-trade-server/src/app.js`
   - 项目名称：`campus-api`
   - 点击启动

### 步骤 5：配置 SSL（可选但推荐）
1. 网站 → 站点设置 → SSL
2. 选择 Let's Encrypt → 申请免费证书
3. 开启强制 HTTPS

## 三、目录结构对应关系

```
服务器:
/www/wwwroot/campus-trade-web/     ← 前端 dist 内容
  ├── index.html
  ├── assets/
  └── favicon.ico

/www/wwwroot/campus-trade-server/  ← 后端代码
  ├── src/
  ├── package.json
  └── ...
```

## 四、更新部署

当代地重新构建后，只需将新的 `dist/` 内容覆盖上传到站点目录即可，无需重启 Nginx。

```bash
# 本地
npm run build
# 上传 dist/ 内容到 /www/wwwroot/campus-trade-web/
```

## 五、常见问题

### Q: 刷新页面 404？
A: 伪静态规则未配置，按步骤 3 重新设置。

### Q: API 请求报 502？
A: 后端 Node.js 未启动或端口不对，检查 PM2 管理器中项目状态，确认端口为 3000。

### Q: 图片上传失败？
A: 检查 Nginx 配置中 `/uploads/` 反向代理是否正确，后端上传目录是否有写权限。

### Q: 前端能访问但接口跨域？
A: 生产环境通过 Nginx 反向代理，不存在跨域问题。确认前端请求路径以 `/api` 开头。
