# 文衡后端 API - 宝塔面板部署指南

## 一、服务器环境准备

在宝塔面板中安装以下软件：
1. **MySQL**（软件商店 → MySQL → 安装 5.7 或 8.0）
2. **PM2 管理器**（软件商店 → 搜索 PM2 → 安装）

## 二、创建数据库

1. 宝塔面板 → 数据库 → 添加数据库
2. 数据库名：`campus_trade`
3. 用户名：`campus_user`（或用 root）
4. 密码：自己设一个，记住
5. 编码：utf8mb4

## 三、上传后端代码

1. 宝塔面板 → 文件 → 创建目录 `/www/wwwroot/campus-trade-server`
2. 将本地 `server/` 目录下所有文件上传到此目录

## 四、配置环境变量

1. 在服务器 `/www/wwwroot/campus-trade-server/` 下复制 `.env.example` 为 `.env`
2. 编辑 `.env`，填入实际配置：

```ini
PORT=3000

DB_HOST=localhost
DB_PORT=3306
DB_NAME=campus_trade
DB_USER=root
DB_PASSWORD=你的MySQL密码

JWT_SECRET=改成一个随机字符串

# 百度OCR（用于书单图片识别）
BAIDU_OCR_API_KEY=你的百度API_KEY
BAIDU_OCR_SECRET_KEY=你的百度SECRET_KEY

# 智谱AI（用于书单文本解析）
AI_API_KEY=你的智谱API_KEY
AI_API_URL=https://open.bigmodel.cn/api/paas/v4/chat/completions
```

## 五、安装依赖并初始化

在宝塔终端中执行：
```bash
cd /www/wwwroot/campus-trade-server
npm install
npm run db:init
```

## 六、用 PM2 启动服务

1. 宝塔面板 → PM2 管理器 → 添加项目
2. 项目名称：`campus-api`
3. 启动文件：`/www/wwwroot/campus-trade-server/src/app.js`
4. 点击启动

或终端执行：
```bash
cd /www/wwwroot/campus-trade-server
pm2 start src/app.js --name campus-api
pm2 save
```

## 七、配置 Nginx 反向代理

在网站设置 → 伪静态中添加（与前端共用）：

```nginx
location /api/ {
  proxy_pass http://127.0.0.1:3000/api/;
  proxy_set_header Host $host;
  proxy_set_header X-Real-IP $remote_addr;
  proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
}

location /uploads/ {
  proxy_pass http://127.0.0.1:3000/uploads/;
}
```

## 八、验证

浏览器访问 `http://你的域名/api/health`，应返回：
```json
{"code":0,"message":"ok"}
```

## 九、AI 服务配置说明

### 百度 OCR（书单图片识别）
1. 访问 https://console.bce.baidu.com/ai/
2. 创建应用，选择"通用文字识别"
3. 复制 API Key 和 Secret Key 到 `.env`

### 智谱 AI（书单文本解析）
1. 访问 https://open.bigmodel.cn/
2. 创建 API Key
3. 填入 `.env` 的 `AI_API_KEY`

> 未配置 AI Key 时，书单解析会使用内置兜底逻辑（按行分割），ISBN 查书仍可用 Open Library + Google Books 免费接口。
